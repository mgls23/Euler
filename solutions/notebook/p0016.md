# Problem 16: Power Digit Sum
---

## Problem Statement
2^15 = 32768 and the sum of its digits is 3 + 2 + 7 + 6 + 8 = 26.

What is the sum of the digits of the number 2^1000?

## Initial Approach
---
The straightforward Pythonic approach: `sum(map(int, str(2**1000)))`

## Naive Array-Based Solution
---
```python
def q16_what_they_want():
	"""Q16 :: Digit of 2^1000 using array multiplication"""
	number, power = 2, 1000
	
	digits = [1]
	for _ in range(power):
		digits = [digit * number for digit in digits]
		for i in range(len(digits)):
			digits[i] *= 2
			if digits[i] >= 10:
				digits[i] -= 10  # Fixed: was just 'digits -= 10'
				assert digits[i] < 10
				
				if i < len(digits) - 1:  # Fixed: was 'i < len(digits)'
					digits[i + 1] += 1
				else:
					digits.append(1)
	
	return sum(digits)
```

### Issues with Original Implementation
1. `digits -= 10` should be `digits[i] -= 10`
2. Boundary condition `i < len(digits)` is always true inside loop
3. Logic for carry-over is broken

## Optimal Solution
---
```python
def q16():
	return sum(map(int, str(2 ** 1000)))
```

**Time**: O(n) where n is number of digits  
**Space**: O(n) for string representation

## Key Insights
---
1. **Python's arbitrary precision**: Built-in support for large integers makes this trivial
2. **String conversion trick**: Convert to string to easily iterate digits
3. **Functional approach**: `map` + `sum` is both readable and efficient

## Alternative Approaches
---
### Using divmod
```python
def digit_sum_divmod(n):
	total = 0
	while n:
		n, digit = divmod(n, 10)
		total += digit
	return total
```

### Manual multiplication (fixed)
```python
def power_digit_sum_manual():
	# Start with 2^0 = 1
	digits = [1]
	
	for _ in range(1000):
		carry = 0
		for i in range(len(digits)):
			prod = digits[i] * 2 + carry
			digits[i] = prod % 10
			carry = prod // 10
		
		# Handle remaining carry
		while carry:
			digits.append(carry % 10)
			carry //= 10
	
	return sum(digits)
```

## Performance Comparison
---
- **Pythonic (str)**: ~0.05ms ⚡
- **Divmod**: ~0.08ms
- **Manual array**: ~15ms (due to list operations)
